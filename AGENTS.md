# Agents

## eBay

- Human approval steps keep us within eBay's terms of service.
- Fast API requests can make it appear otherwise.
- Keep traffic minimal, serial, and paced.
- A refused cookie sends nothing until one is saved.
- Ask before sending a live request by hand.

## Documentation

Never document things we did not do, or decisions we did not make. There are not enough particles in the universe to represent all the documentation we could write about what this app is not.

Never document what something used to be, or how it used to work. Document how it works now. Document future work in the present tense, with a `# To-do` heading above it. Implementing that work deletes the heading.
